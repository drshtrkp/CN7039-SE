# CN7039 Mastery Book 📘

**An interactive study and revision resource for CN7039 – Systems Analysis and Design.**

CN7039 Mastery Book is a browser-based learning website designed to make systems analysis and design concepts easier to explore, practise, and revise. It brings study material together in one accessible place for independent learning and exam preparation.

## Project objectives

- Organise CN7039 learning material into a clear, navigable study guide.
- Support understanding of systems analysis and design through explanations and examples.
- Provide a foundation for interactive revision and self-assessment activities.
- Make the resource accessible on desktop, tablet, and mobile browsers.

## Planned content and features

The study guide is intended to cover:

- Systems analysis and requirements gathering
- Functional and non-functional requirements
- Use case diagrams and UML modelling
- Data flow diagrams (DFDs)
- Class diagrams and object-oriented design
- System design documentation
- Practice questions, quizzes, and revision exercises

> **Note:** The topics above describe the project's intended scope. Available content and interactive features depend on the current version of `index.html`.

## Getting started

### View locally

1. Download this repository as a ZIP file using **Code → Download ZIP** on GitHub.
2. Extract the ZIP file.
3. Open `index.html` in a modern web browser.

### Deploy with Netlify

1. Sign in to [Netlify](https://app.netlify.com/).
2. Select **Add new project / Import an existing project** (the wording may vary).
3. Connect your GitHub account and select `cn7039-mastery-book`.
4. Choose the `main` branch.
5. For a plain HTML/CSS/JavaScript website, leave the **Build command** blank and use `.` as the **Publish directory**.
6. Deploy the site. Netlify will provide a live URL.

Alternatively, deploy the website folder directly using [Netlify Drop](https://app.netlify.com/drop).
